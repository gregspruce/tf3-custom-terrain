# Release notes - Custom Terrain (Experimental)

Paste-ready changelog text for each upload. The game's Mod Hub upload form has one **Changelog** text field and an
**Update Metadata** checkbox (tick it so mod.io gets the new description, summary and cover). mod.io always shows
version "1.0", so each changelog text starts with the update's name. Developer history is in CHANGELOG.md.

## Revision 1 (first release; mod.io 6424823)
```
First release: a Temperate terrain generator built on the vanilla generator, with detailed control over oceans, coastlines, lakes, meandering rivers (widths that grow downstream, deltas, an optional great river), mountains, flat buildable land and transport corridors. Recipes (Easy builder, Challenging terrain, Maritime, Coast to mountains, Alpine, Landlocked, Great plains) set the sliders in one step. Experimental: the river network comes from a script node shipped with the mod.
```
